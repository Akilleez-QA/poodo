# Security policy

## Report a vulnerability

Send suspected security vulnerabilities to craig@nh3.biz. Do not disclose vulnerability details in a public issue.

Include the affected commit or version, reproduction steps, the observed impact, and a minimal sanitized example. State whether the issue involves the skill instructions, validators, or a host integration. Do not include credentials, private conversation records, or customer data.

A structural check does not establish safe behavior by an agent or its host. The skill does not grant authority beyond the user's instructions; host permissions and available tools remain relevant to any report.

## Updates

This policy does not specify a response deadline or a supported-version window. Include the exact affected revision so the report can be assessed against the source.
