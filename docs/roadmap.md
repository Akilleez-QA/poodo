# Roadmap

The initial public project packages the existing POODO 3.0 method with onboarding, synthetic examples, structural tooling, and CI. Future work should follow observed user needs.

## Next evidence to collect

- Clean-context activation checks on named clients and versions.
- A frozen baseline comparison with independent grading and held-out cases.
- Measured context, latency, and cost overhead alongside outcome quality.
- Failure cases where research or 20-path divergence hurts proportionality.
- Continuity checks across multiple capsules and divergent branches.

## Candidate improvements

- A provider-neutral behavioral runner with reproducible records.
- A formal capsule schema and more complete prospective-contract checks.
- A plugin package after installation requirements are tested.
- Additional examples from sanitized real runs, clearly separated from synthetic teaching material.

These are proposals, not delivered capabilities or promises of a release date. Method changes should be compared against the preserved 3.0 baseline.
